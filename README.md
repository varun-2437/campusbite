# CampusBite 🍔

CampusBite is a smart campus food ordering and canteen management system designed to streamline cafeteria operations, reduce queue wait times, and provide seamless order tracking for students and staff.

## 🚀 Key Features

- **Student & Guest Ordering**: Browse real-time menus, customize orders, and checkout seamlessly.
- **Order Tracking & Digital Tokens**: Receive dynamic QR/token updates from order placement to pickup.
- **Role-Based Portals**:
  - **Students / Guests**: Menu browsing, cart, order history, and digital token pickup.
  - **Cashier**: Cash payment verification and token validation.
  - **Kitchen Staff**: Real-time kitchen display system (KDS) and status updates.
  - **Manager / Admin**: Menu curation, inventory management, analytics, and sales reporting.
- **Multiple Payment Options**: Support for online payments (Razorpay) and on-counter cash verification.
- **Inventory Tracking**: Stock management with threshold alerts and automatic menu item availability toggling.

## 🛠️ Tech Stack & Architecture

- **Backend**: Node.js, Express.js / REST APIs, JWT authentication, Role-based access control (RBAC).
- **Database**: Relational / Document Store for users, menu items, orders, payments, tokens, and inventory.
- **Frontend**: Responsive Web / Mobile-friendly interface.
